# 数字花园设计方向

Evan Speak 用主题地图组织个人思考，而不是按发布时间排列文章。它是个人分享站点：内容可以逐步生长，阅读应轻松，页面结构应方便人和 Agent 继续维护。

## 当前站点

- 首页有产品、AI、商业、自我系统、观察五个主题岛屿。岛屿上的文字是 HTML，图像只承担视觉表现。
- 选择岛屿后，右侧显示主题介绍、内容状态、笔记链接，以及进入主题笔记列表和路径页的入口。笔记链接由首页 HTML 中的 `topics` 数据手工维护。
- 文章主要以独立 HTML 页面发布，多数沿用共享阅读样式，并在文末提供“回应的问题”和“关联阅读”。少数文章有独立版式。
- 全站和各主题有笔记列表；`paths/`、`explore/` 及主题路径页目前仍是占位页。
- 站点尚无问题节点数据库、自动反向链接、标签筛选或智能推荐。文章之间的关联由作者在 HTML 中直接编排。

## 内容和视觉原则

- 保留五个主题作为稳定入口，让读者从一个问题或一篇文章继续探索相关内容。
- 以真实的 HTML 文字、链接和状态承载信息；水彩岛屿、纸张纹理、Logo 等图像不包含必须阅读的文字。
- 正文优先保证标题层级、段落节奏、对比度和窄屏阅读体验；装饰和动画不妨碍阅读。
- 关联阅读应指向实际存在的页面，并说明关联缘由。没有合适链接时不为填满版式而添加。
- 内容成熟度可以用状态说明，但公开页面不应保留仅供写作过程使用的备选标题、内部备注等信息。

## 后续演进

问题节点、阅读路径、反向链接和筛选都可以在内容关系足够明确后再做。新增功能应先解决真实的阅读或维护问题，不预设需要知识图谱工具、内容数据库或复杂后台。当前的 HTML 文件和本地工作台足以支持写作、精修与发布。
