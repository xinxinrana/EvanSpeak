# 本地网页工作台

从仓库根目录启动：

~~~bash
node tools/editor/server.mjs
~~~

工作台位于 http://127.0.0.1:8898/ ，本地网站位于 http://127.0.0.1:8898/site/ 。先在本地网站找到要修改的页面，复制 URL 到工作台，再点击“打开网页”。工作台按 URL 路径读取**本仓库已有的 HTML 文件**；粘贴线上网站的对应 URL 也只会打开本地文件，不会读取或修改线上页面。

如果端口已被占用，先停止旧工作台进程。更新 `server.mjs` 后必须重启服务：只刷新浏览器不会重新加载后端代码。

## 编辑和更新

- “页面编辑”允许在完整页面中改文字、插入链接和图片；“HTML 源码”用于修改完整 HTML、布局和脚本。
- 点击“更新 HTML”会直接写回当前本地文件，不需要先保存草稿。图片会写入页面目录的 `images/`。改动经过 Git 提交后才成为可恢复的提交历史。
- 常用文章布局的标题、摘要、分类和状态改动会同步已有列表信息。新页面、独立版式或复杂结构仍需检查首页、主题页和笔记列表。
- 编辑框禁用页面脚本；首页等依赖脚本生成内容的页面，应到本地网站 URL 查看真实运行效果。对于独立版式或需精确保留 HTML 格式的页面，优先使用源码编辑。
- 如果 Agent 或其他工具在打开页面后改了同一个 HTML，工作台会拒绝覆盖。重新打开页面，确认新内容后再编辑。

工作台只编辑已存在的 HTML，不负责新建文章及全部入口的链接维护。旧版工作台留下的本机 JSON 草稿不会自动套用到 HTML，也不会被此流程删除。

## 推送

点击“推送到线上”会先列出**整个本地站点范围**尚未提交的文件，而不只是当前打开的页面；其中也包括 Agent 直接写入的 HTML。确认清单后，工作台在 `main` 分支提交并推送到 `origin/main`。有其他未推送提交或不属于站点范围的已暂存文件时，工作台会停止，需先用 Git 处理。

`docs/`、`tools/`、`AGENTS.md` 等维护文件不在工作台的站点推送范围内，使用 Git 命令单独提交和推送。线上是否更新，以部署完成后访问网站为准。
