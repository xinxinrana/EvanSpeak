# 本地编辑工作台

在仓库根目录运行：

```bash
node tools/editor/server.mjs
```

浏览器打开 http://127.0.0.1:8898/ 。工作台只监听本机 `127.0.0.1`，不需要安装依赖。

选择文章后可以修改标题、摘要、分类、状态、标签、正文和文章末尾的关联信息。普通文章支持可视编辑及 HTML 源码编辑；特殊版式页面使用完整 HTML 源码编辑。右侧随时预览页面。图片按钮会把图片放进文章目录的 `images/` 文件夹。

“保存草稿”写入 `.local-editor/drafts/`，不会改动站点文件；该目录不会提交到 Git。“应用到站点”把草稿写入文章 HTML，并同步首页、主题列表、全站列表和主题文章数量。“下架文章”从本地站点及这些入口移除文章，并保留本机草稿。

应用或下架只改本地仓库，**不会自动推送到线上**。点击“检查并推送”可查看本次工作台登记的站点文件，确认后由工作台提交并推送到 `origin/main`。如果暂存区含有其他文件，工作台会停止推送。若需要 Agent 协助，可以让它直接读取草稿 JSON 或文章 HTML；文章仍以现有 HTML 文件为交付格式。
