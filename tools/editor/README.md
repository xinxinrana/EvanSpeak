# 本地网页工作台

在仓库根目录运行：

~~~bash
node tools/editor/server.mjs
~~~

浏览器打开 http://127.0.0.1:8898/ 。先到 http://127.0.0.1:8898/site/ 查看本地网站，找到要修改的页面并复制 URL。把 URL 粘贴到工作台，点击“打开网页”。也可以粘贴其他本地端口或线上网站的对应页面 URL；工作台按路径打开本仓库中的 HTML 文件。

在页面上直接修改文字、链接和图片；需要调整完整结构时切换到“HTML 源码”。点击“更新 HTML”会直接修改该页面的本地 HTML 文件，无须先创建草稿。Git 会保留文件历史。修改文章标题、摘要或分类时，工作台也会同步现有首页和笔记列表。

确认本地页面后，点击“推送到线上”，检查待提交的站点文件，再确认推送到 origin/main。AI 直接写入或修改的站点 HTML 同样会出现在清单里。工作台不会提交工具代码、文档或本机草稿。

页面编辑使用浏览器原生 contenteditable；工作台禁用页面脚本，避免编辑时触发站点交互。特殊布局或脚本需要精确控制时，使用“HTML 源码”。页面被其他工具修改后，工作台会拒绝覆盖并要求重新打开。
