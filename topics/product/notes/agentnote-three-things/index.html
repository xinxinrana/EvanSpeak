agentNote 项目期望 · 大道至简三件事

agentNote 的定位是用户与 AI agent 之间的显式记忆层。所有能力收敛成三件事：agent 写、agent 读、agent 懂规范 —— 第三条是整套设计的灵魂。

成型
agentNote产品设计边界

agentNote 的期望定位：用户与 AI agent 之间的显式记忆层，以 Obsidian 插件形态落地。

设计哲学「大道至简」——对 agent 的叙事只讲三件事：

  1. agent 写：POST /api/nodes 写入记忆；
  2. agent 读：GET /api/nodes 搜索、读取记忆；
  3. agent 懂规范：每条记忆必带 boundary 三字段（background / scenarios / caveats），这是整个设计的灵魂。

其余能力（s-x 分享活引用、分组、快照）都是这三件事的延伸：代码全部保留、功能正常，但不进入核心叙事。
数据是 vault 里的纯 markdown + JSON，frontmatter 即规范本体；历史交给 git，不做内置版本管理。

截至 2026-07-30，SKILL.md 的具体内容用户认为「还没设计好」，仍在迭代中。

这篇文章回应的问题

一个给 agent 用的记忆层，最少需要讲清楚几件事，才不会失焦。
